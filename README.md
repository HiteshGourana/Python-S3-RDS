# Python-s3-rds

## Overview

The Cloud File Storage System is a web application built using Python Flask and AWS that enables users to securely upload, download, manage, and delete files. The application stores files in Amazon S3 while maintaining file metadata in Amazon RDS (MySQL), providing a secure, scalable, and centralized cloud storage solution.

## Problem Statement

Traditional local storage systems are difficult to scale, offer limited security, and lack centralized file management. This project addresses these challenges by providing a secure cloud-based file storage solution.

## Solution

The application is developed using Python Flask and AWS services. Files are stored securely in Amazon S3, while file information and metadata are maintained in Amazon RDS (MySQL), enabling efficient file management and retrieval.

## Technology Stack

* Python Flask
* Amazon S3
* Amazon RDS (MySQL)
* HTML
* CSS
* Bootstrap
* AWS IAM

## Features

* Secure user authentication
* File upload, download, and deletion
* Centralized file management
* Scalable cloud-based storage
* Secure metadata management using Amazon RDS
